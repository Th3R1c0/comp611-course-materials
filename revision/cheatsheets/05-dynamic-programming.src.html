Section 1: what DP is

[DP-1] DP idea, and DP compared with divide and conquer

DP solves small subproblems first, stores each answer in a table, and reuses them. Use it when there are overlapping subproblems and optimal substructure.

Overlapping means the same small problem is needed many times. Optimal substructure means the best big answer is made of best small answers, like every piece of a shortest path being a shortest path.

D&C: subproblems independent, top down. DP: subproblems overlap, table filled bottom up. Four steps: name the subproblems, base case, recurrence, fill the table.Example: Bellman-Ford and Floyd-Warshall are DP algorithms. Merge sort is D&C.

The base case is the smallest problem you can answer at once. The recurrence is the rule that builds a bigger answer out of table entries already filled in.

Section 2: Longest increasing subsequence (LIS)

[DP-2] Subsequence and increasing

A subsequence keeps the original order but may skip numbers. Increasing means each number is strictly bigger than the one before (equal does not count).Example: in 6, 1, 7, 2, 8, 3 the list 1, 2, 3 is fine, but 7, 6, 8 is not a subsequence because 6 comes before 7.

The numbers do not have to sit next to each other. There can be several different longest ones of the same length.

[DP-3] Fill in the L values

L(i) is the longest increasing run that ends at position i. Go left to right. For each number, look at the smaller numbers to its left. None: L = 1. Otherwise L = the biggest of their L values, plus 1.Example: 5, 2, 8, 6, 3, 6, 9, 7 gives L = 1, 1, 2, 2, 2, 3, 4, 4. For 9: the smaller numbers to its left have L values up to 3, so 3 + 1 = 4.

You are adding this number onto the end of the best increasing run that finishes at a smaller earlier number.

[DP-4] LIS length

The LIS length is the biggest L in the row, not the last one.Example: L = 1, 1, 2, 2, 3, 4, 4, 5, 6, 3 has LIS length 6, even though the last L is 3.

The LIS can end anywhere, so you take the best ending point.

[DP-5] Rebuild an LIS, and running time

Start at a biggest L. Step left to a smaller number with L one less. Repeat down to L = 1, then read it backwards.Example: 9 (L 4), then 6 (L 3), then 3 (L 2), then 2 (L 1). Reversed: 2, 3, 6, 9.

An option is a valid LIS if it keeps the original order, is strictly increasing, and its length equals the biggest L. The P row (predecessors) just records each step back.

Time O(n²) (each number looks back at all earlier ones). Space O(n). Keeping the P row does not change either.

A loop inside a loop over n numbers is n times n. The table is just one row of n numbers.

Section 3: Edit distance

[DP-6] What edit distance is

The smallest number of changes to turn word 1 into word 2. Insert, delete and replace cost 1 each. A match costs 0. Word 1 goes down the side, word 2 across the top, each with an extra empty row or column.Example: CAT to CUT is 1 (replace A with U).

Each box is the edit distance between the start of word 1 up to that row and the start of word 2 up to that column.

[DP-7] Base case: first row and column

The first row and the first column count up 0, 1, 2, 3, … to the word's length.Example: SITTING across the top gives 0, 1, 2, 3, 4, 5, 6, 7 (8 boxes).

Turning nothing into 3 letters takes 3 inserts. Turning 3 letters into nothing takes 3 deletes.

[DP-8] Fill one box (colour key: up, left, diagonal)

1. Read off up, left and diagonal (up and to the left). 2. Work out up + 1, left + 1, and diagonal + 0 if the two letters are the same or + 1 if different. 3. Write the smallest.Example: up 3, left 2, diagonal 2, letters different: 4, 3, 3, so the box is 3. Same letters: just copy the diagonal.

Up plus 1 is a delete, left plus 1 is an insert, and the diagonal is a match (free) or a replace (cost 1). The row letter is the letter of word 1 on that row, and the column letter is the letter of word 2 on that column.

[DP-9] Answer, edit sequence, and running time

The edit distance is the bottom-right box. An edit list is optimal if it has that many changes and really makes word 2.Example: SNOWY to SUNNY is 3: insert U, replace O with N, delete W.

For very short words you can often count the changes directly, then check against the options.

The table has (m + 1) times (n + 1) boxes. Time O(mn) and space O(mn).Example: SUNDAY and SATURDAY: 7 times 9 = 63 boxes.

Each box only looks at 3 neighbours, so it is a fixed amount of work per box.
