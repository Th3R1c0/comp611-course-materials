Section 1: valid flows, size and cuts

[FN-1] Valid flow: two rules

A label 3/5 means flow 3, capacity 5. Capacity rule: flow is never more than capacity. Conservation: at every vertex except s and t, total in equals total out.Example: B has in 1 + 3 = 4 and out 4, so it passes. A label 3/2 breaks the capacity rule.

s is the source (where flow starts) and t is the sink (where it ends). They are the only vertices allowed to have in different from out.

[FN-2] Size (value) of a flow

|f| = add the flows on the edges leaving s. It equals the flow entering t.Example: S to A is 3 and S to C is 7, so |f| = 10.

Use the first number of each label (the flow), not the capacity.

[FN-3] Capacity of a cut

Left side has s, right side has t. Add the capacities of edges going left to right only. Edges going right to left are not counted.Example: left {S, A, B}: S to C 8, A to D 2, B to T 6, so 16. C to B goes right to left, so skip it.

A cut is a set of pipes that, if removed, would stop all flow from s to t.

[FN-4] Max-flow min-cut

Every flow is at most every cut. Max flow = min cut capacity. A flow and a cut with the same number prove both are best.Example: flow 10 and cut {S, A, C} with capacity 10, so the max flow is 10.

For a small graph, try the obvious cuts (just s on the left, everything but t on the left, the narrow middle) and take the smallest.

Section 2: Ford-Fulkerson, residual networks, Edmonds-Karp

[FN-5] Residual network

For an edge with flow f and capacity c: forward room = c minus f, and a reverse edge with room f. Room 0 means the edge is left out.Example: 1/3 gives forward 2, reverse 1. A full edge 4/4 gives forward 0 (gone), reverse 4.

The reverse edge lets a later path undo flow sent earlier, so a bad first choice can be fixed.

[FN-6] Ford-Fulkerson steps

1. Start at zero flow. 2. Find a path s to t with room on every edge (an augmenting path). 3. Bottleneck = smallest room on it. 4. Add it to the total and take it off each edge's room. 5. Repeat until no path is left.Example: rooms 7, 4, 5 give bottleneck 4. Paths 1, 2, 3, 4 on the lab network give totals 1, 3, 6, 10.

Keep a table: path, room on each edge, bottleneck, total so far. Remember to use the room left, not the original capacity, on later paths.

[FN-7] Minimum cut from the end

When it stops, the vertices you can still reach from s using edges with room form the left side. The cut edges are the full edges from left to right, and their capacities add up to the max flow.Example: S reaches A and C only, so the cut is A to B, A to D, C to B, C to D: 1 + 2 + 3 + 4 = 10.

If a question gives the final residual network, just follow edges with room from s.

[FN-8] Running times, Edmonds-Karp, bipartite matching

AlgorithmPath choiceTime
Ford-Fulkersonany pathO(m times f*)
Edmonds-KarpBFS, fewest edgesO(n m²)

n is vertices, m is edges, f* is the max flow value. Ford-Fulkerson depends on the flow value because each path might only add 1.

Bipartite matching: add s joined to every left item, every right item joined to t, every capacity 1. Max flow = biggest matching.Example: 4 workers and 4 jobs, max flow 3 means at most 3 pairs can be made.

Capacity 1 stops any worker or job being used twice.
