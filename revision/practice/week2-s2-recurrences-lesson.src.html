Topic 2 · Write the recurrence from pseudocode (sheet [DC-5])

2A Fast steps: turn code into T(n) = aT(n/b) + f(n)

No calculator needed

  1. a = how many recursive calls actually run in one go of the function. Count the lines where the function calls itself. Trap: if the two calls are in an if / else, only one of them runs, so a = 1 (binary search).
  2. n/b = the size of each call's input. If each call gets half the list, write n/2 (b = 2). If each gets a third, write n/3 (b = 3).
  3. f(n) = the work done outside the recursive calls, read with week 1's loop rules ([AA-12]):
    only simple lines (compare, add, return, max of two) give Θ(1)
    one loop over the n items (merge, count, copy, print) gives Θ(n)
    a loop inside a loop over n gives Θ(n²)
  4. Write it: T(n) = a T(n/b) + f(n).
  5. Why: the total time is the time of the smaller jobs (a of them, each T(n/b)) plus the extra work this call does itself.

Example: majority element (lab 2)

MAJORITY(A, lo, hi) if lo == hi: return A[lo] mid = ⌊(lo+hi)/2⌋ left = MAJORITY(A, lo, mid) ← call 1, half size right = MAJORITY(A, mid+1, hi) ← call 2, half size for each cand in {left, right}: count cand in A[lo..hi] ← a loop over n, twice = still Θ(n)

Step 1: a = 2 calls. Step 2: each gets n/2, so b = 2. Step 3: outside the calls, counting is a loop over the n items, so f(n) = Θ(n).

T(n) = 2T(n/2) + Θ(n)

Example: binary search (the trap)

The code has two recursive lines, but they're in "if target < A[mid] … else …", so only one runs. Outside the call: one comparison, so Θ(1).

T(n) = T(n/2) + Θ(1), not 2T(n/2)

Topic 3 · Solve a recurrence with a recursion tree (sheet [DC-6], [DC-7])

3A What a recursion tree is

  1. Draw the first call at the top (level 0). Under it draw its a recursive calls (level 1), under each of those their a calls (level 2), and so on, down to the base cases (the leaves).
  2. Write inside each box the extra work f that call does. Then add up each level, then add up all the levels. That total is T(n).

Merge sort, n = 8: every level costs 8 in total, and there are log₂ 8 = 3 levels of splitting (plus the leaves). So the total is about 8 × 3. In general n × log₂ n, which is Θ(n log n).

3B Fast steps: any recursion tree question

Calculator: yes The calculator does every power for you: type the number, then ^, then the power.

  1. Step 1: read off a (number of calls) and b (what n is divided by) from T(n) = aT(n/b) + f(n).
  2. Boxes at level i: type a^i. Level 0 has 1, level 1 has a, level 2 has a×a.
  3. Size at level i: type b^i, and the size is n divided by that answer.
  4. Cost of one box = f of its size. If f(n) = n² and the size is n/4, one box costs (n/4)² = n²/16.
  5. Level total = number of boxes times the cost of one box.
  6. Height (number of levels of splitting) = log_b n, because you divide by b until you reach 1.
  7. Number of leaves = n to the power p. Type log a ÷ log b to get p. Example: 4T(n/2) gives log 4 ÷ log 2 = 2, so n² leaves.
  8. Same, shrink or grow? When f(n) is a power of n, call the power k and type a ÷ b^k.
    If the answer is exactly 1, every level does the same work, so the total is one level times log n.
    If it is less than 1, the levels shrink and the top level wins, so the total is Θ(f(n)).
    If it is more than 1, the levels grow and the leaves win, so the total is Θ(n^p).

Example: T(n) = 3T(n/4) + n² (from the lecture)

Calculator: yes

Step 1 a = 3, b = 4, k = 2 Step 2 level 2: boxes = 3^2 = 9, size = n ÷ (4^2) = n/16 Step 3 same, shrink or grow: 3 ÷ 4^2 = 3 ÷ 16 = 0.1875 Step 4 less than 1, so the levels shrink and the top wins

T(n) = Θ(n²)

Example: T(n) = T(n/2) + n

Calculator: yes

Step 1 a = 1, b = 2, k = 1 Step 2 1 ÷ 2^1 = 0.5 Step 3 less than 1, so the levels shrink (n, n/2, n/4 and so on, less than 2n)

T(n) = Θ(n)

3C The three ways to solve a recurrence (name questions)

  1. Substitution method: guess the answer, then prove it by induction (show that if it works for smaller sizes, it works for n). The most general method, but you need a good guess.
  2. Recursion tree method: draw the tree, add each level, add the levels. Often used to make the guess for substitution.
  3. Master Theorem: a ready-made formula for recurrences shaped T(n) = aT(n/b) + f(n). Fastest when it applies (topic 4).
