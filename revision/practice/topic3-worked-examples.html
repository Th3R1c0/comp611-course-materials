Proving bounds with c and n₀: worked examples

Every topic 3 question from the practice set, solved with the same steps, plus extra examples.

Step 1 Always unpack it into two sides first

  1. Left = the function.
  2. Right = c × (whatever is inside the brackets). c always goes on the right.
  3. The sign comes from the letter: O → ≤ (at most, a ceiling) · Ω → ≥ (at least, a floor) · Θ → both.
  4. n₀ is the number you put in place of every n, on both sides. It is not a multiplier.
"f(n) = 4n + 9 is O(n)" → 4n + 9 ≤ c × n "f(n) = 3n² + 5n + 2 is Ω(n²)" → 3n² + 5n + 2 ≥ c × n² "2n² = O(n)" → 2n² ≤ c × n
Golden rule for checking: check at n = n₀ and at a big n like 100. A ceiling or floor must hold for every n, not just the first one.

Case A "Find c": use the recipe

  1. O (ceiling): c = add up all the numbers (skip ones with a minus), n₀ = 1.
  2. Ω (floor): c = the front number of the biggest term, n₀ = 1.

Example A1: 4n + 9 is O(n)

Ceiling, so add up the numbers.

4 + 9 = 13 → c = 13, n₀ = 1 n = 1: left 4×1 + 9 = 13 right 13 × 1 = 13 13 ≤ 13 ✓ n = 100: left 409 right 1,300 409 ≤ 1,300 ✓

c = 13, n₀ = 1

Example A2: 3n² + 5n + 2 is Ω(n²)

Floor, so take the front number of the biggest term (3n²).

c = 3, n₀ = 1 n = 1: left 3 + 5 + 2 = 10 right 3 × 1 = 3 10 ≥ 3 ✓ n = 100: left 30,502 right 30,000 30,502 ≥ 30,000 ✓

c = 3, n₀ = 1

Case B They give options: test each one

  1. Write the option's c into the right side.
  2. Replace every n with the option's n₀ and work out both sides. Check the sign.
  3. Then check n = 100. An option must pass both.
  4. Shortcut: if the Case A recipe answer is one of the options, that's the answer.

3.1: f(n) = 5n² + 2n + 7. Which (c, n₀) proves it's O(n²)?

Unpack: 5n² + 2n + 7 ≤ c × n². Recipe: 5 + 2 + 7 = 14, and option A is c = 14, n₀ = 1. Checking all four anyway:

A c=14, n₀=1: left 5+2+7 = 14 right 14×1 = 14 14 ≤ 14 ✓ (n=100: 50,207 ≤ 140,000 ✓) B c=5, n₀=1: left 14 right 5×1 = 5 14 ≤ 5 ✗ C c=7, n₀=1: left 14 right 7×1 = 7 14 ≤ 7 ✗ D c=4, n₀=10: left 500+20+7 = 527 right 4×100 = 400 527 ≤ 400 ✗

Answer A

3.2: f(n) = 3n² + 8n + 1. Which (c, n₀) proves it's Ω(n²)?

Unpack: 3n² + 8n + 1 ≥ c × n². Recipe: the front number of 3n² is 3, and option B is c = 3, n₀ = 1. This one shows why you must check n = 100 too:

B c=3, n₀=1: n=1: 12 ≥ 3 ✓ n=100: 30,801 ≥ 30,000 ✓ C c=4, n₀=1: n=1: 12 ≥ 4 ✓ n=100: 30,801 ≥ 40,000 ✗ (passes at n₀, breaks later!) D c=12, n₀=1: n=1: 12 ≥ 12 ✓ n=100: 30,801 ≥ 120,000 ✗ A 'no such constants exist': wrong, because B works

Answer B

3.5: Which pair does NOT prove 3n + 10 = O(n)?

Unpack: 3n + 10 ≤ c × n. Find the option that fails.

A c=5, n₀=5: left 15+10 = 25 right 5×5 = 25 25 ≤ 25 ✓ B c=4, n₀=10: left 30+10 = 40 right 4×10 = 40 40 ≤ 40 ✓ C c=3, n₀=100: left 300+10 = 310 right 3×100 = 300 310 ≤ 300 ✗ D c=13, n₀=1: left 3+10 = 13 right 13×1 = 13 13 ≤ 13 ✓

Answer C. With c = 3 the right side is 3n, and 3n + 10 is always 10 more.

Case C "Why can't it be proven?"

  1. Find the function's growth (its fastest term, number dropped) and what's in the brackets.
  2. Look both up in the growth order: 1 → log n → n → n log n → n² → n³ → 2ⁿ.
  3. For O: if the brackets are left of (slower than) the function, it's impossible. Pick the answer that says "n keeps growing but c is fixed".

3.3: Why can no constants prove 2n² = O(n)?

Unpack: 2n² ≤ c × n. The function grows like n², and the brackets have n, which is slower, so it's impossible. To see it break with c = 1,000:

n = 1: left 2 right 1,000 ✓ n = 500: left 500,000 right 500,000 ✓ (just) n = 1,000: left 2,000,000 right 1,000,000 ✗ Any c breaks once n passes c ÷ 2. You're comparing 2n against c: 2n keeps growing, c is stuck.

Answer C

Extra C2: Is n³ = O(n²)?

n³ is right of n² in the growth order, so the brackets are slower.

n³ ≤ c × n² means n ≤ c, but n keeps growing past any fixed c.

Impossible. It's not O(n²).

Case D There's a minus sign: find the smallest n₀

  1. Unpack as usual. n²/2 means n × n ÷ 2. (1/4)·n² means n × n ÷ 4.
  2. Test each n₀ option, smallest first, by replacing n with it.
  3. The first option that passes is the answer.

3.4: What's the smallest n₀ so that n²/2 − 4n ≥ (1/4)·n²?

Options sorted: 1, 8, 16, 32.

n = 1: left 1÷2 − 4 = −3.5 right 1÷4 = 0.25 −3.5 ≥ 0.25 ✗ n = 8: left 64÷2 − 32 = 0 right 64÷4 = 16 0 ≥ 16 ✗ n = 16: left 256÷2 − 64 = 64 right 256÷4 = 64 64 ≥ 64 ✓ ← first pass (n = 32 also passes, but it isn't the smallest)

Answer 16, which is option B

Extra D2: What's the smallest n₀ (from 1, 3, 6, 10) so that 2n² − 6n ≥ n²?

Test smallest first.

n = 1: left 2 − 6 = −4 right 1 ✗ n = 3: left 18 − 18 = 0 right 9 ✗ n = 6: left 72 − 36 = 36 right 36 ✓ ← first pass

Answer 6
